# AI Smart Math & Expression Solver

An advanced Python-based mathematical expression evaluator and AI reasoning assistant. It safely computes complex expressions, identifies mathematical patterns, and provides natural-language analysis of mathematical inputs.

## Features
- **Safe Evaluation:** Built-in sandboxed expression parsing.
- **AI Heuristics & Insights:** Analyzes equations to classify expression types (Algebraic, Trigonometric, Geometric, etc.) and evaluates complexity.
- **Calculation History:** Logs past computations with clean terminal output.

## Usage
```bash
pip install -r requirements.txt
python app.py
